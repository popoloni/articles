# The Economics of AI Loops — Version 2.0

Reproducible companion package for Enrico Papalini's article.

## Deliverables

- `output/article.pdf` — compiled article (15 pages)
- `src/article.tex` — standalone LaTeX source
- `src/ai_economics_model.py` — Python implementation of all calculations and figures
- `MATH_MODEL.md` — formal model specification and interpretation
- `data/model_prices_2026-07-24.csv` — dated official price snapshot
- `data/assumptions.json` — all scenario and local-runtime assumptions
- `output/*.csv` and `output/results_summary.json` — calculated outputs
- `figures/*.png` and `figures/*.pdf` — generated publication figures
- `src/generated_values.tex` — values generated by Python and consumed by LaTeX

## Evidence classes

The package deliberately distinguishes:

1. **Sourced observations:** current official provider prices, cited research, GitHub billing changes, and author-supplied local telemetry.
2. **Scenario assumptions:** production acceptance rates, review time, expected rework/risk, retry-stage probabilities, and capacity changes for the regulated-maintenance case.
3. **Calculated results:** context costs, cost per accepted outcome, retry-policy expectations, break-even values, bottleneck throughput, verification leverage, and uncertainty ranges.

Public benchmark scores are not used as production acceptance probabilities.

## Reproduce the model

```bash
cd ai_economics_v2
python src/ai_economics_model.py
```

This regenerates all figures, CSV results, the JSON summary, and `src/generated_values.tex`.

## Compile the article

```bash
pdflatex -interaction=nonstopmode -output-directory=output src/article.tex
pdflatex -interaction=nonstopmode -output-directory=output src/article.tex
```

## Key calculated results

- 40-turn Sonnet 5 context cost:
  - full replay: **$6.48**
  - compaction: **$2.28**
  - fresh context with external state: **$1.96**
- Complete scenario cost per accepted outcome:
  - local Qwen route: **$96.08**
  - Gemini 3.6 Flash: **$74.88**
  - Claude Sonnet 5: **$61.75**
  - Claude Opus 4.8: **$53.38**
- Hybrid local-local-Opus cascade: **$62.53 expected completed outcome cost**
- Monte Carlo 10th–90th percentile: **$53.96–$75.41**
- Infrastructure-only local break-even:
  - Gemini 3.6 Flash: **68 tasks/month**
  - Sonnet 5: **56 tasks/month**
  - Opus 4.8: **25 tasks/month**
- Throughput constraint: **52 → 64 outcomes/month** after verifier investment
- Verification leverage: **4.0x**

## Interpretation warning

The case demonstrates a method, not a universal ROI claim. Replace the scenario assumptions with homogeneous production cohorts before making investment, staffing, or routing decisions.
