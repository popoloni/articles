# The Economics of AI Loops — Markdown edition

This package contains a Markdown version of the article with all visual content embedded as JPEG assets.

## Main file

- `article.md`

## Visual assets

- `assets/banner.jpg`: final minimalistic article banner
- `assets/figure_01.jpg` through `figure_10.jpg`: all article figures
- `assets/table_01.jpg` and `table_02.jpg`: LaTeX tables rendered as JPEG
- `assets/equation_01.jpg` through `equation_12.jpg`: displayed formulas rendered as JPEG

## Source and reproducibility

The `source/` folder contains the LaTeX source, generated values, Python model, frozen data, and calculated results.

All JPEGs use a white background and high-quality 4:4:4 encoding for publication compatibility.
