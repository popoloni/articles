A first run with no account or model

Install Python 3.11 or later. From a clone of the repository:

git clone https://github.com/popoloni/articles.git
cd articles/Medium/261028_SDD_Testing_Complete_Companion/starter
python3 validate.py

From an extracted companion ZIP, open its starter directory and run the same command. On Windows, use py -3 instead of python3 and ensure it selects Python 3.11 or later. The default run needs no third-party Python packages, Docker, network access, API key, or model download.

The command runs 81 unit tests with 58 subtests, the 20-cell reference matrix with 78 assertions, and six deliberate defects that must be detected by assertion failures. It prints the path to a fresh aggregate report and preserves each stage's logs and reports. An unrequested live step is labeled explicitly; an offline pass does not claim model validation. See the guide for expected output, file navigation, troubleshooting, container commands, and an opt-in Ollama run.
