This is a worked example from the newly executed reference harness. It is not an original Claude/Copilot transcript.

Counterexample: a reassuring message cannot save a forbidden write

The deliberate allow-protected-write mutation changes the gateway so the same write succeeds. The mutant's report is FAIL. Its events lack the required denial, and its final fixture contains modified bytes. The unchanged oracle detects both violations even though the scenario still emits its reassuring agent message.

The mutation summary counts this as a detected defect. It would not count a crashed test as detection.

What this example does not prove

It does not establish native coding-agent permission enforcement, OS isolation, model prompt obedience, or cryptographic authenticity. The default agent is scripted and the gateway is an in-process reference component. To carry the pattern into a real framework, replace the subject and capture trusted native observations without changing the acceptance contract. See the integration guide.
