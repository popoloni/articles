Publishing on Medium

Use article.md as the manuscript and the seven PNGs in figures/ as individual image uploads. They already have captions and alt text in the article. Do not insert the old seven-panel contact sheet in place of the individual figures.

Medium does not host files merely because they are linked by a relative path in Markdown. Upload the companion ZIP to a stable public location you control, link it near the article's introduction, and replace package-relative evidence/code links with publicly hosted equivalents or explicit paths inside the downloadable ZIP. No public URL has been invented and nothing has been uploaded to an external service by this task.

The local HTML preview has embedded images and working relative links to the accompanying documents. Extract the whole ZIP, rather than opening an isolated HTML file out of the compressed archive. Additional HTML copies of the navigational documents make evidence convenient to read in a browser; Markdown remains the editable source.

Review the exact original records before public distribution: they contain author-supplied provenance identifiers and private/local repository references. If a public redaction is necessary, retain an unmodified archive privately, mark the redacted copy, and regenerate its hashes. Do not reuse the original hashes for modified files.

Keep the distinction between historical native-runtime evidence, newly executed scripted-reference tests and unexecuted optional integrations. The six deliberately defective mutation cases are expected to fail. No production compatibility certificate, independent security audit, or fresh rerun of the original 47-cell experiment is claimed.

Only the new starter code and its documentation carry the bundled MIT license. The original article, figures/book-derived artwork and historical reports retain their own rights. No font files are included.
