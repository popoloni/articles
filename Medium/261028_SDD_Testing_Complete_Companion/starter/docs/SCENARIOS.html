The six deliberately broken cases

The mutation implementation temporarily permits a protected write; removes denial observations; accepts stale/self reviews; makes rollback a no-op; removes exposure evidence; and bypasses tool policy. Each selected scenario must produce explicit failed assertions. An exception, timeout, or uncollected test is not a successful detection.

The retained mutation reports contain the expected red results. A red result there is intentional; it must not be mixed into the normal matrix as a production defect.
