# Article website — corrected installer and preview

The earlier preview used Python's plain HTTP server. This caused a 404 if `docs/` had not been built, the command was run outside the repository, or `/articles/` was opened instead of `/`. This release adds a setup command and a preview server that supports **both URLs**.

## Quick start (Mac)

1. Stop the previous HTTP server with **Ctrl+C** in its Terminal window.
2. Extract this ZIP. Open Terminal in the extracted directory.
3. Install Pandoc once, if necessary: `brew install pandoc`.
4. Run:

   ```sh
   bash setup_article_site.command
   ```

   The installer finds an existing Git checkout containing `Medium/` or clones `https://github.com/popoloni/articles.git` beside the installer. If your checkout is elsewhere, provide its path:

   ```sh
   bash setup_article_site.command "$HOME/path/to/articles"
   ```

   It builds the actual committed articles with Pandoc, checks their relative repository targets, verifies `docs/index.html` and each reading page, then starts the preview only after success. It prints the exact absolute repository and output paths. No commit, push, reset or pull is performed automatically. Your original `Medium/` files are unchanged. A nonempty `docs/` directory that was not generated by this tool is protected from replacement.

5. Open **http://localhost:8000/articles/** (also http://localhost:8000/). Both work. Leave the Terminal running while previewing. If port 8000 is occupied, run the installer with `--port 8001` and open the printed address.

For a build without launching the server, use `--build-only`.

## If the archive is already extracted inside your existing checkout

```sh
python3 scripts/build_article_site.py
python3 scripts/preview_article_site.py
```

The preview server resolves `docs/` relative to the script's absolute location, not the current working directory. It refuses to start if the homepage is missing. If building fails, address the printed error rather than starting the old HTTP server.

## Deploy after reviewing locally

From the repository root:

```sh
git add docs scripts/article_catalog.json scripts/build_article_site.py scripts/preview_article_site.py scripts/articles.css scripts/articles.js setup_article_site.command INSTALL_ARTICLE_SITE.md
git commit -m "Publish searchable article archive"
git push origin main
```

In GitHub Settings → Pages select Deploy from a branch → `main` → `/docs`. This matches the Pages configuration observed in the previous build logs. The `.nojekyll` marker serves the static HTML directly. Check that the Pages Actions run succeeds; then visit https://popoloni.github.io/articles/.

To add another article, commit the Markdown and assets under `Medium/`, add its metadata to `scripts/article_catalog.json`, and rerun the installer or the two individual commands. The generated website uses the committed source revision. Commit-pinned images and companion links require that revision to be available on GitHub; push original article changes first if needed. Archive dates are repository collection dates (the Apple Silicon guide uses its stated July 2026 evidence date); reading times are estimates.
